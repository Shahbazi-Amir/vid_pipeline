# Persian benchmark

Benchmark fixtures should cover clear speech, noise, proper names, numbers,
Arabic phrases, silence, short audio, a chunk boundary, and long audio.

Report duration, audio extraction, ASR, merge, cleanup, review and total time,
real-time factor, profile, worker count, and model. Report CER and WER only
against a verified reference transcript. Synthetic fixtures are smoke tests,
not evidence of real-world accuracy.
